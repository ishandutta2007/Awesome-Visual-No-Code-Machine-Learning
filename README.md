# Awesome-Visual-No-Code-Machine-Learning

## Top Visual No-Code Machine Learning Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on AutoML, Drag-and-Drop Model Building & Democratized AI*  

**Last updated: October 2026**



This repository tracks notable **commercial no-code ML platforms** and **open-source projects** that let users build, train, and deploy machine learning models without writing code. These tools range from automated machine learning (AutoML) services to visual pipeline builders and self-hosted AutoML libraries.



**Examples** include Amazon SageMaker Canvas, DataRobot No-Code, Pecan AI, Akkio, Obviously AI (Zams), Google Vertex AI AutoML, Azure Machine Learning Designer, MakeML, MonkeyLearn, and Create ML (the category leaders).



**Open-source emphasis**: Visual no-code ML is a growing open-source domain. **Zero2Neuro** provides a no-code toolbox for constructing, training, and evaluating DNNs . **SwiftPredict-v2** delivers lightweight AutoML with experiment tracking and a web UI . **AutoGluon**, **MLJAR**, and **PyCaret** offer Python-based AutoML with minimal coding. **KNIME**, **Orange**, and **RapidMiner** bring visual workflow-based ML. This section is heavily expanded.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[Amazon SageMaker Canvas](https://aws.amazon.com/sagemaker/canvas/)**  

  **AWS's no-code ML platform** — generate predictions without writing code . Supports **numeric prediction, classification, time series forecasting, image prediction, and text prediction** . Features **generative AI foundation models** for content generation and document querying . **Ready-to-use models** powered by Amazon Rekognition, Textract, and Comprehend . **Best for AWS users wanting no-code ML with deep AWS integration**.



- **[DataRobot No-Code](https://www.datarobot.com/)**  

  **Enterprise AutoML with no-code applications** — visualize, optimize, and interact with ML models without building them . **Best for enterprises wanting governed AutoML**.



- **[Pecan AI](https://www.pecan.ai/)**  

  **Predictive AI agent for business outcomes** — churn prediction, LTV modeling, lead scoring, and demand forecasting without a data science team . **90% of predictions delivered without data science support** . **Best for CRM-integrated predictive analytics**.



- **[Akkio](https://www.akkio.com/)**  

  **No-code predictive analytics for business analysts** — connect datasets, build models, and deploy to production with spreadsheet-level knowledge . **Best for business analysts wanting predictive insights**.



- **[Google Vertex AI AutoML](https://cloud.google.com/vertex-ai)**  

  **Google's AutoML for image and tabular data** — classification, regression, and object detection without code . **Best for Google Cloud users wanting AutoML**.



- **[Azure Machine Learning Designer](https://azure.microsoft.com/en-us/products/machine-learning/)**  

  **Drag-and-drop ML pipeline builder** — train models without writing code . **Best for Azure users wanting visual ML**.



- **[Zams (formerly Obviously AI)](https://www.zams.ai/)**  

  **No-code AI agent and predictive model builder** — build classification and regression models without coding . **Best for GTM teams wanting AI agents**.



- **[MakeML](https://makeml.app/)**  

  **No-code object detection and segmentation** — train neural networks without programming . **Best for computer vision without code**.



- **[MonkeyLearn](https://monkeylearn.com/)**  

  **No-code text analysis** — sentiment analysis, keyword extraction, and categorization . **Best for text classification without code**.



- **[Create ML](https://developer.apple.com/machine-learning/create-ml/)**  

  **Apple's no-code ML for macOS/iOS** — train models on Mac with no code. **Sensitivity 93.24%, specificity 98.48%** in clinical image classification . **Best for Apple ecosystem developers**.



## Open-Source GitHub Projects



- **[Zero2Neuro](https://github.com/Symbiotic-Computing-Laboratory/zero2neuro)**  

  **No-code toolbox for constructing, training, and evaluating DNN models**, open-source with NSF funding . **Supports FCNs, CNNs, and U-Nets** — user specifies structural details without coding . **Handles CSV data loading, model creation, training, and evaluation** with Weights & Biases hooks . **Best for researchers wanting no-code deep learning**.



- **[SwiftPredict-v2](https://pypi.org/project/swiftpredict-v2/)**  

  **Lightweight AutoML with FastAPI backend and Python SDK**, open-source . **Single `fit()` call handles null imputation, encoding, feature selection, scaling, class imbalance, multi-model training, cross-validation, and experiment logging** . **Local web UI with no dependencies** . **Best for developers wanting AutoML with experiment tracking**.



- **[AutoGluon](https://github.com/autogluon/autogluon)**  

  **AWS's open-source AutoML toolkit** — 3 lines of code for state-of-the-art models. **Best for Python users wanting minimal-code AutoML**.



- **[PyCaret](https://github.com/pycaret/pycaret)**  

  **Low-code ML library for Python** — automate ML workflows with minimal code. **Best for rapid prototyping**.



- **[MLJAR AutoML](https://github.com/mljar/mljar-supervised)**  

  **Automated ML with explainable results** — generates Markdown reports. **Best for interpretable AutoML**.



- **[KNIME](https://github.com/knime/knime-core)**  

  **Visual workflow-based data science** — drag-and-drop ML pipelines. **Best for visual data science workflows**.



- **[Orange](https://github.com/biolab/orange3)**  

  **Visual programming for data mining and ML** — widgets-based interface. **Best for education and visual ML**.



- **[RapidMiner](https://github.com/rapidminer/rapidminer)**  

  **Visual ML platform** — drag-and-drop model building and deployment. **Best for enterprise visual ML**.



- **[H2O AutoML](https://github.com/h2oai/h2o-3)**  

  **Open-source AutoML from H2O.ai** — automatic model selection and tuning. **Best for scalable AutoML**.



- **[TPOT](https://github.com/EpistasisLab/tpot)**  

  **Genetic programming-based AutoML** — optimizes ML pipelines. **Best for pipeline optimization**.



### Additional Strong Open-Source Options



- **Ludwig** — No-code ML framework from Uber, YAML-based model definition.

- **AutoKeras** — AutoML for deep learning, Keras-based.

- **MLBox** — AutoML for data preparation and model optimization.

- **Auto-ViML** — AutoML with explainability focus.

- **Featuretools** — Automated feature engineering.

- **Sklearn-genetic** — Genetic algorithm-based feature selection.



**Frameworks for building custom no-code ML solutions**: Combine **AutoGluon** for minimal-code AutoML with state-of-the-art performance. Use **SwiftPredict-v2** for AutoML with experiment tracking and local UI . Deploy **Zero2Neuro** for no-code DNN construction with FCNs, CNNs, and U-Nets . Choose **KNIME** or **Orange** for visual workflow-based ML. Note that true enterprise no-code ML with governed AutoML, CRM integration, and business-outcome predictions (DataRobot, Pecan, SageMaker Canvas) remains primarily commercial territory; open-source stacks provide strong AutoML, visual workflow, and no-code DNN foundations that require integration for complete enterprise deployment.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- No-code ML platforms handle sensitive business and potentially personal data. **Review data privacy policies** — cloud platforms may use data for model improvement. Self-hosted solutions require proper security hardening.

- **No-code ML has trade-offs** — reduced flexibility, limited hyperparameter tuning, and dependency on high-quality labeled data . Complex problems may still require code-based approaches.

- **Open-source AutoML tools vary in maturity** — AutoGluon and PyCaret are production-ready; Zero2Neuro and SwiftPredict-v2 are actively developed research tools . Evaluate before deployment.

- The open-source ecosystem provides strong AutoML, visual workflow, and no-code DNN foundations, but **governed AutoML, CRM integration, and business-outcome predictions** remain primarily commercial offerings.
